集成OCR、Excel处理和Neo4j知识图谱构建的API系统

🔗 快速链接

首页 健康检查 系统信息 OpenAPI规范

📚 API端点

GET /
系统首页
获取系统基本信息和状态
GET /health
健康检查
检查系统运行状态和各服务健康状况
GET /system/info
详细系统信息
获取系统配置、版本、运行时间等详细信息
POST /api/ocr/upload
OCR文件上传
上传PDF文件进行OCR处理和知识图谱构建
参数: files (文件列表), case_name (案件名称)
GET /api/ocr/tasks
获取OCR任务列表
查看所有OCR处理任务的状态
GET /api/ocr/task/{task_id}
获取任务详情
根据任务ID获取具体任务的处理进度和结果
POST /api/excel/analyze
Excel数据分析
上传Excel文件进行程序性违法查询分析
参数: file (Excel文件), case_name (案件名称)
POST /api/neo4j/query
Neo4j图数据库查询
执行Cypher查询语句，检索知识图谱数据
参数: query (Cypher查询语句)
GET /api/neo4j/stats
数据库统计信息
获取Neo4j数据库节点和关系的统计数据

💡 使用示例

# Python使用示例
import requests

# 健康检查
response = requests.get("http://localhost:8000/health")
print(response.json())

# 上传文件进行OCR处理
files = {'files': open('document.pdf', 'rb')}
data = {'case_name': '测试案件'}
response = requests.post("http://localhost:8000/api/ocr/upload", files=files, data=data)
print(response.json())
